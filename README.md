# Self-Service Reseller Portal — Independent Demo

A synthetic, responsive browser demo of product specifications, tiered pricing and quick quote generation.

**Context:** Real-world professional work on a private reseller portal reduced turnaround from about seven days to two. This independent portfolio demo did not produce that business metric.

Open `index.html` in a browser. No backend, authentication, live ERP connection or real commercial prices are included. All SKUs and products are fictional.
